## 📂 Featured Internship Projects Showcase

### 1. 🏛️ JOMBE DIGITAL — Integrated Public Administration & Governance System
> *Full-Stack Web & Mobile Public Service Platform with Zero-Trust Security*

- **GitHub Repository**: [`asaduljie/Website_Pelayanan_Desa_Jombe`](https://github.com/asaduljie/Website_Pelayanan_Desa_Jombe)
- **Tech Stack**: Next.js 14 (App Router), TypeScript, Express.js, Prisma ORM, PostgreSQL, Flutter (Android), PDFKit, Baileys WhatsApp Gateway.
- **Key Features & Engineering Highlights**:
  - **Unified Realtime Backend**: Satu REST API melayani aplikasi web masyarakat, dashboard operator desa, dan aplikasi mobile Flutter.
  - **Zero-Trust Security**: Enkripsi AES-256-GCM pada data NIK/PII, proteksi BOLA/IDOR, dan *Binary Magic Bytes Check* untuk mencegah web shell/malicious file upload.
  - **Dynamic Form & Request Tracking**: Pengajuan surat otomatis (SKU, SKTM, Domisili) dengan nomor resi unik berformat `JMB-2026-XXXXX`.
  - **Automated PDF Generator**: Otomasi pembuatan surat ber-kop desa resmi secara instan berdasarkan input data pemohon.
  - **Plan B Offline Assisted Flow**: Modul operator untuk melayani warga lansia dengan tanda terima otomatis via WhatsApp Bot.
